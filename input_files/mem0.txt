Mem0 is memory layer for personalized AI. During memory construction, given a message, Mem0 uses a large language model to extract a list of key facts. Each fact in the list is then directly used as a query to search the memory store at the current time step for similar memory units. Based on the extracted facts and the retrieved similar memory units, the large language model decides whether to create new memory units, update existing ones, or delete existing ones. During the retrieval stage, Mem0 directly uses the user’s input as the query to retrieve relevant memory units from the memory store. Finally, these retrieved memory units are passed to a downstream question-answering model to generate the response.
