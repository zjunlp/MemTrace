EverMemOS is a memory system that constructs long-term personal memories from dialogue streams and retrieves them through an adaptive multi-round pipeline. During memory construction, each incoming message is first appended to a running buffer, and the system checks whether the current buffered context should continue accumulating or be closed as a coherent segment. Once a segment is closed, EverMemOS finalizes it into an identifiable event memory unit, enriches it with episode-level information and optional retrieval-oriented fields such as event logs or foresight, indexes the refined memory for later retrieval, and then resets the buffer under a smart-mask strategy. During retrieval, EverMemOS first performs hybrid retrieval with the user query to obtain an initial candidate pool. It then builds an evidence set, optionally reranks it, and uses a large language model to judge whether the retrieved evidence is sufficient for answering the query. If the evidence is sufficient, EverMemOS returns the top-ranked memories from the first retrieval round. Otherwise, it generates follow-up queries from the missing-information signals, performs a second round of hybrid retrieval, and fuses the additional candidates with the initial pool. Finally, EverMemOS deduplicates candidates by event identity, applies a final reranking or truncation step to select the top-k memory context, and passes the retrieved context to the downstream question-answering model to generate the response.
